# Contributing to ADE

Thank you for helping improve the public ADE interface.

## Contribution boundary

This repository contains a public interaction layer, draft contracts, examples, and documentation. Contributions must stay within the scope visible in this repository. Do not submit confidential material, credentials, private datasets, or material that you are not entitled to publish.

## Pull request structure

Keep each pull request bounded and reviewable. Describe:

1. the goal;
2. the exact files and behavior in scope;
3. the constraint or defect being addressed;
4. the evidence used;
5. the verification performed;
6. any unresolved condition.

A proposal is not treated as a verified result merely because it was submitted.

## License

## Developer Certificate of Origin

Every commit must include a `Signed-off-by` line certifying the Developer Certificate of Origin 1.1 in `DCO.md`.

Create a signed-off commit with:

```bash
git commit -s -m "Describe the bounded change"
```

The sign-off must use a name and email address that identify the contributor. It is a certification of origin and permission, not a cryptographic signature.

Commits without the required sign-off are not eligible for merge.
